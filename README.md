# TabKeep Site

Static presentation site for the TabKeep iOS app.

Open `index.html` directly, or serve the folder with any static server.

The App Store badges point to `https://apps.apple.com/app/id6766437336`.
If the listing URL changes, set `TABKEEP_DOWNLOAD_URL` in `script.js` or replace
the `href` values in `index.html`.

The Open Source section links to the Swift Package dependencies resolved from
`project.yml`: Grovs iOS SDK, GoogleSignIn-iOS, AppAuth-iOS, and GTMSessionFetcher.
